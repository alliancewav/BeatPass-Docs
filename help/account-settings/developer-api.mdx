Use **Developers** in Account Settings to create or remove access tokens for an approved integration. Treat each token like a password: it lets an application act with the access your account has.

<ApiInviteOnly />

## Create a token

<Steps>
  <Step title="Open Developers">
    Open [Account Settings](https://open.beatpass.ca/account-settings#developers) and select **Developers**. This section appears only when API access is available to your account.
  </Step>
  <Step title="Give the token a name">
    Select **Create token**. Enter a **Token name** of 3 to 100 characters that identifies the application, then select **Create**.
  </Step>
  <Step title="Save the token once">
    Select **Copy**, store the token securely, then select **Done**. The full token cannot be viewed again after closing the dialog.
  </Step>
</Steps>

## Remove access

Find the token in **Developers**, select **Delete**, and confirm **Delete token?**. The application using that token loses access. Deleting a token does not change your password or sign out your browser.

If a token is lost or exposed, delete it and create a replacement. Update the intended application with the replacement; never send tokens to support or include them in screenshots.

## Continue with an integration

Use the [developer quickstart](/developers/quickstart) for integration instructions. If **Developers** is missing, [contact support](/help/contact-support) about access rather than creating another account.
