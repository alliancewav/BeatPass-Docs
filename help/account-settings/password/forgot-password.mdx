Recover your BeatPass sign-in with a password reset email. You can also use this flow to create a password if you originally joined with Google.

## Send yourself a reset link

<Steps>
  <Step title="Open password recovery">
    On the [sign-in page](https://open.beatpass.ca/login), select **Forgot password?** below **Password**.
  </Step>
  <Step title="Enter your account email">
    Enter **Email address** for your BeatPass account and choose **Send reset link**. BeatPass returns you to sign-in after the email request succeeds. Check your inbox and spam or junk folder.
  </Step>
  <Step title="Use the email link">
    Open the link within **60 minutes**. On **Create new password**, enter **Email address**, **New password**, and **Confirm password**, then select **Reset password**.
  </Step>
  <Step title="Sign in again">
    Use the new password to sign in. Other browser sessions may also need to sign in again.
  </Step>
</Steps>

The new password must have at least **8 characters**, and both password fields must match.

## The email or link did not work

- Check that you entered the email for the right account and that your mailbox can receive mail.
- Allow time for delivery, then request a fresh link if needed. Use the newest email.
- If a link has expired or was already used, choose **Send a new reset link** when offered, or return to password recovery. If you pasted a link, make sure you included the whole address.
- If connected Google sign-in still works, you can use **Continue with google** to access the account while sorting out password recovery.

If you cannot access your email, try recovering that mailbox first. [Contact BeatPass support](/help/contact-support) if you still need help. Do not send your password, reset link, or recovery codes.
