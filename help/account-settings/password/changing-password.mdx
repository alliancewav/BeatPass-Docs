Change your BeatPass password when you know the current one. If you do not know it, including when you have only used Google, use [email recovery](/help/account-settings/password/forgot-password).

## Update your password

<Steps>
  <Step title="Open Password">
    Open [Account Settings](https://open.beatpass.ca/account-settings#password) and select **Password**. The form is titled **Update password**.
  </Step>
  <Step title="Enter the current and new passwords">
    Fill in **Current password**, **New password**, and **Confirm password**. Use at least **8 characters** for the new password and enter the same value in both new-password fields.
  </Step>
  <Step title="Save the new password">
    Select **Update password**. Wait for confirmation before leaving. Use the new password the next time you sign in; other browser sessions may require you to sign in again.
  </Step>
</Steps>

If the current password is rejected, use email recovery rather than repeatedly guessing. If the new fields do not match, clear both and re-enter the same password.

Choose a password you do not use elsewhere. Change it if you believe it was shared or exposed, and review [Active sessions](/help/account-settings/active-sessions).
