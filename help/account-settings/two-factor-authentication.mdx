Add two-factor authentication to your BeatPass password sign-in with codes from an authenticator app. Keep recovery codes as a backup so a lost device does not leave you without a way to sign in.

## Set up your authenticator

<Steps>
  <Step title="Enable the extra sign-in check">
    Open [Account Settings](https://open.beatpass.ca/account-settings#two-factor), select **Two factor authentication**, and select **Enable**. Confirm your password if asked.
  </Step>
  <Step title="Add BeatPass to your authenticator">
    Scan the QR code with your authenticator app. If scanning is unavailable, enter the displayed **Setup key** in the app instead.
  </Step>
  <Step title="Confirm a code">
    Enter the app's current code in **Code**, then select **Confirm** to finish enabling the check.
  </Step>
  <Step title="Save the recovery codes">
    Store the displayed codes somewhere you can reach without the authenticator device. Treat the QR code, setup key, and recovery codes as secrets.
  </Step>
</Steps>

## Sign in with a code

After your password, enter the authenticator's current code and select **Continue**. If the code is rejected, check your device's automatic time, wait for a fresh code, and confirm you selected the BeatPass account in the authenticator.

If you cannot use the authenticator, select **Use recovery code instead** and enter an unused saved recovery code. Each recovery code works once.

## Replace recovery codes or change devices

While signed in, select **Regenerate recovery codes** in the same settings section. Confirm your password when prompted and save the replacement codes. The old codes stop working.

To replace the authenticator itself, make sure you still have account access, select **Disable**, then enable the check with the new authenticator. Disabling removes the extra check until setup is completed again.

If both the authenticator and recovery codes are unavailable, [contact support](/help/contact-support). Do not send a password, setup key, QR code, or recovery code in a support message.
