Use this guide if an existing Stripe Connect payout route needs attention. Subscription card payments are a different task; use [payment help](/help/troubleshooting/payment-issues) for those.

## Check the active route in Finances

Open [Producer Dashboard → Finances](https://open.beatpass.ca/producer-dashboard/finances). Review **Payout setup** and the status for the earning type involved. A connected destination is not the same as a completed payment.

New and resumed Stripe onboarding are closed. If offered, use **Set up BEATPAY** rather than opening a new Stripe account. An eligible legacy route can stay active until BEATPAY is ready for the relevant earnings; earlier routed earnings keep their provider history.

## Existing Stripe requirements need attention

Use the available Stripe account access or [Stripe Express login](https://connect.stripe.com/express_login) for the connected account. Check pending verification, payout, and bank requirements there. Creating a separate regular Stripe account will not reconnect the legacy route.

If BeatPass does not offer an action you expect, [contact support](/help/contact-support) with the status shown. Do not repeatedly try new or resumed onboarding.

## A payout has not arrived

Check the transaction and selected earning period in Finances:

- A queued or processing record is not proof of bank arrival.
- An already routed payout can retain its earlier provider even after a setup change.
- Different currencies are not directly interchangeable; read the currency and amount on each record.
- Bank timing, compliance review, receiving-bank charges, and conversions can affect arrival.

Use the transaction or payout reference when contacting support. Send the status and currency, not full account numbers or identity documents unless requested through an appropriate process.

## Bank details need changing

Manage a legacy Stripe destination through the connected Stripe Express account. For an active BEATPAY route, follow the bank setup or update action shown in Finances and use the [BEATPAY guide](/help/earnings/beatpay).

BeatPass retains operational references and masked payout details; providers have their own retention and verification duties. Read the [Privacy Policy](/help/legal/privacy-policy) for those boundaries.
