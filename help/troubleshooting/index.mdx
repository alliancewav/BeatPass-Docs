## Quick Fixes

Before reloading, keep any unsaved work and wait for uploads or payments already in progress. Avoid repeating a purchase while you are checking its result.

<AccordionGroup>
  <Accordion title="Check your connection">
    Try another website to see whether the problem affects your connection. Return to the same BeatPass page when the connection is stable.
  </Accordion>
  <Accordion title="Reload when your work is safe">
    On a computer, use **Ctrl+R** on Windows or **Cmd+R** on Mac. On your phone, use the browser's reload action. Check whether the same issue returns before repeating other actions.
  </Accordion>
  <Accordion title="Compare with another browser">
    Try the same task in another modern browser. This can help identify a browser-specific problem without clearing your current session.
  </Accordion>
  <Accordion title="Check an extension">
    If an extension appears to block a control or file, temporarily disable it and check the same page again.
  </Accordion>
  <Accordion title="Clear site data only if you need to">
    Clearing BeatPass site data can sign you out and remove saved browser state. Keep needed records first. Use this after a normal reload or another browser has helped identify a local storage problem.
  </Accordion>
</AccordionGroup>
