License presets let you save an exclusive license configuration and reuse it on future beats. They are useful when you want consistent exclusive terms without rebuilding the same setup every time.

## What a Preset Stores

A BeatPass exclusive preset stores the license configuration itself, including:

- Publishing split
- Territory
- Governing law country
- Usage rights
- Files to deliver
- Producer royalty
- Content ID and other exclusive toggles

<Note>
  Presets are for the **exclusive configuration**. Price and other track-specific choices should still be reviewed on each beat.
</Note>

## How Saved Terms Work in the Producer UI

The exclusive configuration form includes **Start from saved terms**:

- Choose an existing item under **Saved terms** to load it into the current beat.
- Choose **Custom configuration** when you want to work directly from the current fields.
- Click **Reset** to return to the BeatPass starting configuration.
- Click **Use as my default** to save the current terms as your personal starting point for future exclusive-capable beats.

<Note>
  **Use as my default** saves the license configuration, not the track's price or availability. Delivery guarantees are confirmed separately for each beat.
</Note>

Applying saved terms does not change another beat. The selected values are copied into the current form, where you can review them before saving. Sold beats keep the terms already recorded in the buyer's certificate.

## Best Practices

- Use **Use as my default** only after you have reviewed every term.
- Keep your personal default aligned with the deal structure you use most often.
- Recheck governing law, optional permissions, and promised files on every beat.
- Use **Customize percentages** only when a financial preset does not fit the deal.
