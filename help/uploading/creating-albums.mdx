Group related beats into a **collection**, such as a beat pack, tape, or themed drop. Start in [My Collections](https://open.beatpass.ca/producer-dashboard/albums), or turn on **Create collection** before uploading several WAV files.

<CollectionCatalogFigure />

## Create a collection

From **My Collections**:

<Steps>
  <Step title="Open My Collections">
    Click your **profile avatar**, select **Producer Dashboard**, then open **My Collections**.
  </Step>
  <Step title="Create the collection">
    Select **Create collection**. Add the beats that belong to this release in the collection editor.
  </Step>
  <Step title="Complete the collection details">
    Add collection metadata, cover art, and any optional description details.
  </Step>
  <Step title="Review the tracks">
    Make sure each track has its own required fields completed, then save. Reopen the collection from **My Collections** to check its artwork and track order.
  </Step>
</Steps>


## Add the collection details

| Field | Required? | Notes |
|-------|-----------|-------|
| **Name** | Yes | Collection title |
| **Cover Art** | Yes | Required for new collections |
| **Release date** | No | A calendar date for the release; setting a future date does not schedule or hide the published collection |
| **Artists** | Yes | Credited producers |
| **Genres** | No | Helps with discovery |
| **Tags** | No | Helpful keywords |
| **Description** | No | Context for the release |

<Note>
  New tracks added inside a collection still need their own audio upload and cover art to pass BeatPass validation.
</Note>

## Check each beat

New beats uploaded inside a collection start with its **Artists**, **Genres**, and **Tags**. Review those starting values for each beat before saving.


## Managing Tracks Inside a Collection

Open an existing collection to:

- **Upload beats** to add new tracks
- Adding **existing tracks** from your catalog
- Editing individual tracks
- Removing tracks from the collection
- Reordering tracks

If an action is unavailable, check whether you manage the collection or only contributed a beat. Removing a beat from a collection changes its grouping; it does not delete the beat from your catalog.


## Best Practices

<AccordionGroup>
  <Accordion title="Use collections when the release really belongs together">
    Collections work best when the beats share a theme, sonic direction, or release concept.
  </Accordion>

  <Accordion title="Keep the cover art consistent with the release">
    Collection cover art is one of the first things buyers and listeners will see.
  </Accordion>

  <Accordion title="Review track-level requirements carefully">
    Even inside a collection, each beat still needs its own valid audio, cover art, and required metadata.
  </Accordion>
</AccordionGroup>
