## How Messaging Is Accessed

<Steps>
  <Step title="Open the header icon">
    Click the **message** icon in the top navigation to open the messaging panel.
  </Step>
  <Step title="Choose a conversation or start a new one">
    Select a recent chat or click **New Message** to create a new conversation.
  </Step>
  <Step title="Send messages in the same panel">
    The conversation view, input box, and management menu all live inside the same messaging UI.
  </Step>
</Steps>

<Note>
  Use the expand control in the panel to open the full [Messages workspace](https://open.beatpass.ca/messages). On desktop, it fills the available screen while the list and conversation scroll independently.
</Note>

## What Messaging Supports

| Capability | Current behavior |
| --- | --- |
| **Direct messages** | Start a private conversation with an existing BeatPass user |
| **Group chats** | Start a group with 2 or more other users from the new message flow |
| **Message suggestions** | Blank search shows followed users first |
| **User search** | Search starts after you enter at least 2 characters |
| **Conversation tools** | Search, pin, mark read or unread, follow or unfollow, archive, restore, and report |
| **Live states** | Typing indicators, unread counts, seen state, failed-send retry |

</Info>

## Privacy & Safety

Messages are not public posts. Authorized administrators can review conversations and reported exchanges for moderation.

<Warning>
  Never share passwords, payment credentials, or other sensitive information through direct messages.
</Warning>

If someone is abusing messaging:

1. Open the conversation menu and choose **Report conversation**.
2. Choose a reason, add relevant details, and submit.
3. Archive the conversation if you want it out of your inbox.

See [Reporting conversations](/help/messaging/reporting-conversations) for what a report includes. Administrators can follow [Moderating messages and reports](/help/messaging/moderation).
