## Start a conversation

<Steps>
  <Step title="Open Messages">
    Select the **message icon** in the top navigation, then **New Message**.
  </Step>
  <Step title="Choose a person">
    Select someone you follow, or enter at least two characters to search by username or producer name. Follow the person if prompted.
  </Step>
  <Step title="Send your first message">
    Write your message and select **Send Message**. On desktop, **Enter** also sends; **Shift + Enter** adds a line. On mobile, Return adds a line, so use the send button.
  </Step>
</Steps>

Your message appears in the conversation. **Sent** means BeatPass accepted it; **Seen** means it has been read. If you see **Failed**, use the offered retry control. Check the thread before sending again when delivery is uncertain.

<Tip>
  You must follow a person to message them. They must follow you to reply. Neither person needs a producer profile or upload access.
</Tip>

## Start from a profile

Open a user profile or a claimed producer page and select **Message** when available. Follow the person's user account if prompted, then send your message in the panel. An existing conversation reopens so you can pick up where you left off.

## Keep the conversation going

Messages support text and clickable links, with up to **2,000 characters** per message. Find recent chats in the conversation list; unread badges help you spot replies. Opening a thread marks its unread messages as read.

Hover a message to see its timestamp. Your own messages can show **Sending...**, **Sent**, **Seen**, or **Failed**. See [Reactions and message status](/help/messaging/real-time-features) for reactions, typing indicators and delivery help.
