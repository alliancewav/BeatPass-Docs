Apply a BeatPass promo code before completing a subscription checkout. Codes are not supported for exclusive beat purchases.

## Apply your code

<Steps>
  <Step title="Enter Promo code">
    Start checkout for your chosen plan. Open **Add a promo code**, then enter it in **Promo code**.
  </Step>
  <Step title="Apply and check">
    Select **Apply code** and wait for the updated summary. Check that the discount appears before paying. The summary still includes the applicable platform fee.
  </Step>
  <Step title="Review the renewal total">
    Current codes apply to one payment. Check both today's amount and the recurring amount for later renewals before selecting **Subscribe**.
  </Step>
</Steps>

Only one code can be applied to a checkout. Use **Remove code** before trying another. Codes are normalized to uppercase, so letter case alone should not prevent a valid code from applying.

## If the code is rejected

Read the error beside **Promo code**. Check the code, expiry, eligible plan, and any use or first-purchase limits attached to the offer. An inactive or exhausted code will not apply.

If a payment option does not support promo codes, the checkout explains the available alternative. Entering a code does not change an already completed payment.

For a code that still seems valid, [contact support](/help/contact-support) with its text, the plan, and the displayed error. Do not include payment secrets.
