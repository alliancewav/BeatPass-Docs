The **My Beats** page keeps catalog work in one place. Search your beats, open insights, review editable legacy details, and explore collaboration connections for each producer profile you manage.

<ProducerOnly />

## How to Get Here

Click your **profile avatar** → **Backstage**, then select **My Beats** in the sidebar.

If your account manages more than one producer profile, use **Artist profile** to choose the catalog you want to review. Changing profiles resets the current filters, selected beats, and page.

## Beat Catalog

**Beat catalog** is the main working section. It shows 20 beats by default, with 10, 20, or 50 beats per page, and keeps each row readable on desktop, tablet, and mobile.

Each beat shows:

- Artwork and beat name
- BPM, key, scale, and duration
- Collection name or **Single**
- Licensing choice
- **Plays** (all-time audience plays)
- Last update date
- **Feature**, **Insights**, and **Edit** actions

<Note>
  **Audience plays** counts BeatPass listening activity from people outside the selected producer's team. A real zero stays visible. **Unavailable** means BeatPass could not load that play information.
</Note>

### Filters

- **Needs review** — Beats whose artwork cannot be displayed or whose genre, BPM/key/scale, or licensing information needs review
- **Singles** — Beats that are not in a collection
- **In a collection** — Beats assigned to a collection
- **Collaborations** — Beats credited to more than one producer

Use **Filter** to add or remove a catalog view or license type. With no filters applied, the table shows all beats and all licensing choices.

### Licensing Choices

- **Standard**
- **Standard and exclusive**
- **Exclusive only**

Select the **Plays** or **Updated** column heading to sort the whole catalog. Select the same heading again to reverse the order; select it a third time to return to the default newest-first order.

### Actions and Selection

- **Upload beat** opens the beat upload flow.
- **Feature** makes an eligible beat the first beat on the selected producer's Pro Page.
- **Remove featured beat** clears your saved choice so BeatPass can select an available beat.
- **Insights** opens detailed performance information for one beat.
- **Edit** opens the beat editor.
- Use the checkbox beside any beat to select it, or use **Select all on this page** above the list. **Clear selection** leaves every beat unselected. Use **Delete selected** only when you intend to permanently remove the selected beats.

Collection names open the connected collection. Use **Items per page** to show 10, 20, or 50 beats. Use **Previous** and **Next** below the list to move between pages. The range text shows which beats are currently visible, and **Updating** indicates a background refresh without hiding the current rows.

### Featured Beat

You can save one featured beat for each producer profile you own. Featuring another beat replaces the previous choice for that profile.

The **Feature** action is available when the selected producer is the primary owner, the audio is playable, and at least one active licensing or purchase path exists. For an AI-assisted beat, you must also confirm that you hold the commercial rights. An exclusively sold beat cannot be featured for new customers. When the action is unavailable, its explanation points to the field or offer that needs attention.

The public Pro Page uses the saved choice when it is still available. Otherwise it selects another available beat instead of presenting an unavailable offer.

## Review Details

The upload flow requires cover art, a playable audio file, a producer credit, genre information, BPM, key, scale, rights declarations, and a valid licensing choice before a new beat can be published. **My Beats** does not repeat audio or producer credits as separate warnings. It does flag artwork that can no longer be displayed, which can happen to an older or imported beat after upload.

For older or imported catalog entries, **Needs review** identifies editable information that can affect discovery or licensing:

- **Artwork** — Neither the beat artwork nor its collection artwork can be displayed
- **Genres** — No genre is attached to the beat
- **BPM, key, or scale** — One or more musical details is missing
- **Licensing** — The licensing choice or required exclusive-offer details are incomplete

Rows that need attention state the exact details beside the beat metadata. Use **Edit** to correct them.

## Collaborations

**Current collaborators** lists producers already credited with the selected artist and shows their collaborative-beat counts. Verified profiles keep their blue check beside the producer name. Use **Chat** when the collaborator has one connected producer account, or use **View collaborative beats** to apply the matching catalog view.

**Artists with shared genres** compares the canonical genres on producer profiles. Suggestions exclude the selected producer and current collaborators. Each suggestion shows the full number of genres in common and at most two genre names. BeatPass does not display an invented score or default genre.

When a suggested artist has a connected producer account, select **Chat** to open a conversation. Select the artist name to review the profile first.

If the selected producer profile has no genres, use **Add genres to artist profile** before using this section for suggestions.
