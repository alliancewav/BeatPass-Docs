The **My Beats** page is your dashboard-level catalog view. It combines summary cards, a searchable track table, growth guidance, and collaboration tools for your current artist.

## How to Get Here

Click your **profile avatar** → **Backstage**, then select **My Beats** in the sidebar.

## Growth Status

The page header summarises play activity for your current artist. It compares local BeatPass plays from the latest 30 days with the preceding, non-overlapping 30 days. Select the help icon to see the definition, thresholds, data floor, and improvement tips.

| Label | Threshold and behavior |
| --- | --- |
| **Growing** | Above +5% |
| **Steady** | From −5% through +5%, inclusive |
| **Needs attention** | Below −5% |
| **Building play data** | Fewer than 10 combined plays across both periods |
| **Play trend unavailable** | The comparison could not be calculated or loaded |

The **Play change** value divides the difference between the periods by the busier period. It is rounded to one decimal when needed and stays naturally between **−100% and +100%** without truncating high-growth results. For example, 237 recent plays compared with 42 previous plays is **+82.3%**. No previous plays with current activity is **+100%**; previous activity with no current plays is **−100%**; equal counts are **0%**.

<Note>
  This trend counts BeatPass `track_play` activity for the artist's resolved tracks. It does not use contribution value, imported lifetime plays, payout data, or Pro Page traffic.
</Note>

## Track Table

The main working area on the page.

### Columns

| Column | What it shows |
| --- | --- |
| **Track** | Artwork and track link |
| **Artist** | Primary artist |
| **Duration** | Track length |
| **Plays** | Play total |
| **Growth** | Recent BeatPass momentum badge for tracks gaining listener activity |
| **Points** | Contribution points |
| **Last uploaded** | Upload date |
| **Actions** | Quick links for **Insights** and **Edit** |

### Available Actions

- **Upload new track** — opens the upload flow
- **Insights** — opens the track's backstage insights page
- **Edit** — opens the track editor
- **Delete selected** — appears when you select rows

### Filters

- Artwork
- Album
- Plays count
- Date uploaded
- Licensing
- Points

<Note>
  Track-level growth badges show recent listening momentum. They are separate from **Points** and do not change payout or contribution calculations. Full editing still happens in the backstage track editor.
</Note>

## Collaboration Insights

Focuses on people already connected to your catalog.

- Total collaborator count
- Collaborative-track count
- A ranked list of top collaborators
- A detail modal when more collaboration data is available

## Collaboration Recommendations

Suggests artists to explore next based on your genre profile and catalog data.

- Your top genres used as recommendation context
- Suggested artists with similarity signals and shared genres
- A **View Profile** action for each suggestion

If BeatPass does not have enough data, the section encourages you to build your catalog before inventing recommendations.

## Empty States

  </Accordion>
  <Accordion title="No recommendation data yet" icon="wand-magic-sparkles">
