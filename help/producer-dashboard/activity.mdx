The **Activity** page puts audience downloads and listener response first. It also keeps a current-year calendar of your track uploads.

<ProducerOnly />

## Open Activity

Click your **profile avatar** in the top navigation bar, select **Backstage**, then select **Activity** in the sidebar.

The page opens with **Last 90 days** selected. Change **Activity period** to **Last 7 days**, **Last 30 days**, **Last 90 days**, or **All time**. This setting updates **Audience activity** and **Recent downloads**.

## Audience Activity

**Audience downloads** is the main number. It counts track downloads by listeners who do not manage your artist profile. Repeat downloads count each time.

| Metric | What it shows |
| --- | --- |
| **People downloading** | Distinct listener accounts that downloaded at least one track |
| **Licenses issued** | License certificates issued during the selected period |
| **Audience plays** | Plays by listeners, including signed-out listeners |
| **Likes** | Track likes created during the selected period |
| **Reposts** | Track reposts created during the selected period |
| **Comments** | Visible track comments created during the selected period |

When one track has the most downloads in the selected period, **Top downloaded track** links directly to it.

<Note>
  Downloads and licenses do not need to match. One listener can download the same track more than once while using one license.
</Note>

Select **What counts?** for these definitions without leaving the page. Select **How Activity works** to reopen this guide in a new tab.

## Recent Downloads

Each row includes the track, listener, download time, and a license action when an active certificate exists. Expired or revoked certificates are identified with plain text.

- Select the track name or artwork to open the track
- Select the listener name to open their profile
- Select **View license** to open an available certificate in a new tab
- Use **Previous** and **Next** to move between groups of eight download records

The page number and visible record range stay above and below the list. If another page cannot load, the current records stay in place. Select **Try Again** to retry, or **Previous** to return to the earlier page.

The list follows the selected **Activity period** and does not use a separate scroll area.

## Upload Rhythm

**Upload rhythm** shows the current calendar year. Each square represents one day. A stronger accent means more of your tracks were uploaded on that day.

Select an active day to see its upload count and track list. On mobile, the calendar opens at the most recent week and scrolls horizontally.

### X-Ray

**X-Ray** is on when the page opens. It adds days when other BeatPass tracks were uploaded.

- **You** uses the accent colour for your uploads
- **BeatPass uploads** uses a muted colour for other platform uploads
- The pulse highlights days revealed only by X-Ray

X-Ray provides upload context. It is not a score, ranking, or measure of success. If X-Ray is unavailable, your own upload calendar stays visible.

## Empty and Unavailable States

<AccordionGroup>
  <Accordion title="No tracks" icon="cloud-arrow-up" defaultOpen>
    Select **Upload your first track** to open the upload page. Activity appears after tracks are available to listeners.
  </Accordion>
  <Accordion title="No audience downloads" icon="download">
    The page names the selected period. Select **View all time** to check your full download history.
  </Accordion>
  <Accordion title="A section is unavailable" icon="triangle-exclamation">
    Select **Try Again** in that section. Other sections remain available while it reloads.
  </Accordion>
</AccordionGroup>
