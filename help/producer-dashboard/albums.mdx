The **My Collections** page helps you organize beats into releases and correct missing release details. It keeps collection work separate from general catalog statistics so the next useful action stays clear.

<ProducerOnly />

## How to Get Here

Click your **profile avatar** → **Backstage**, then select **My Collections** in the sidebar.

If your account manages more than one producer profile, use **Artist profile** to choose the collections you want to review. Changing profiles resets the current filters, selection, and page.

## Collections

**Collections** is the main working section. It shows 20 collections by default, with 10, 20, or 50 collections per page, and preserves useful release information on mobile.

Each collection shows:

- Artwork and collection name
- Release date or **Release date not set**
- Track count, including a real zero
- **Plays** (all-time audience plays across the collection's beats)
- Last update date
- **Insights** and **Edit** actions

<Note>
  **Audience plays** counts BeatPass listening activity from people outside the selected producer's team. A real zero stays visible. **Unavailable** means BeatPass could not load that play information.
</Note>

### Filters

- **Needs review** — Collections whose artwork cannot be displayed, release date is not set, or beat list is empty
- **Upcoming** — Collections with a future release date
- **Released** — Collections whose release date is today or earlier
- **Empty** — Collections with no beats

Use **Filter** to add or remove a collection view. With no filter applied, the table shows all collections.

Select the **Plays** or **Updated** column heading to sort the whole catalog. Select the same heading again to reverse the order; select it a third time to return to the default recently-updated order.

### Actions and Selection

- **Create collection** opens the collection editor.
- **Insights** opens detailed performance information for one collection.
- **Edit** opens the collection editor.
- Use the checkbox beside any collection to select it, or use **Select all on this page** above the list. **Clear selection** leaves every collection unselected. Use **Delete selected** only when you intend to permanently remove the selected collections.

Use **Items per page** to show 10, 20, or 50 collections. Use **Previous** and **Next** below the list to move between pages. The range text shows which collections are currently visible, and **Updating** indicates a background refresh without hiding the current rows.

## Release Details

**Release details** provides planning guidance and leads back to filtered collections. It does not represent a separate publication gate.

| Issue | What to Review |
| --- | --- |
| **Artwork unavailable** | The collection artwork cannot be displayed |
| **Release date not set** | No release date is set |
| **No beats added** | The collection does not contain any beats |

Select **Artwork unavailable**, **Release date not set**, or **No beats added** to apply the matching **Needs review** filter and return to **Collections**. New collections require artwork, but artwork on an older or imported collection can stop loading later. When current collections have working artwork, a release date, and at least one beat, the section shows **Release details are complete**.

If a future release exists, **Next upcoming release** links to the closest collection by release date. Upcoming and released labels always use the collection's release date, not the date it was created.

## Collections on Your Pro Page

A collection appears on the public Pro Page only when it has public beats that visitors can play and explore. If no usable collection exists, the public page omits the Collections section.

When a visitor selects a collection, the Pro Page filters the catalog in place instead of sending them away from the producer storefront. The collection remains in the page URL so Back, Forward, and a copied browser URL restore the same catalog view.

Use collections for a real listening path—a beat tape, album, campaign, or focused sound—not simply to fill space on the page.
