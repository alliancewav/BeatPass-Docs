BeatPass uses four rarity labels to describe achievement milestones.

## Current rarity labels

| Label | Meaning |
| --- | --- |
| **Common** | An accessible milestone in the collection |
| **Rare** | A less common producer milestone |
| **Epic** | A demanding milestone |
| **Legendary** | The highest rarity in the current collection |

## How rarity appears

Rarity appears as text alongside achievement status and category. Available and unlocked achievements use the same neutral card design, so color and decoration do not carry the meaning.

## Rarity and XP

Rarity and XP are separate. Do not estimate a reward from rarity alone. An available achievement shows its potential XP, while an unlocked achievement shows the XP actually awarded.

A real 0 XP unlock can exist at any configured rarity and still count toward collection progress.
