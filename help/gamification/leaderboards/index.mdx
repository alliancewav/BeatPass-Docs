The leaderboard page lets you compare your producer ranking against other producers across several categories.

## Getting There

Open your **Producer Dashboard** from the sidebar, then choose **Leaderboards**.

## What You See

| Element | Description |
| --- | --- |
| **Your rank** | Appears in the rankings header when you are in the displayed top 50 |
| **How rankings work** | Opens a concise explanation of the current ranking method |
| **Ranking selector** | Switches between Overall, Plays, Uploads, Earnings, and Collaboration |
| **Rankings list** | Displays the top 50 producers for the selected category |

## Current Scope

- The leaderboard uses five producer-facing category views
- There is no genre selector — rankings are not genre-specific
- There is no timeframe selector — rankings reflect cumulative activity

See [Leaderboard Categories](/help/gamification/leaderboards/categories) for the full list and descriptions.
