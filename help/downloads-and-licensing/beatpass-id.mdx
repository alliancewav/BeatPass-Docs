BeatPass ID brings a track’s licensing model, sample declaration, AI-use disclosure when available, promised exclusive deliverables, and verified audio fingerprint into one provenance record. The fingerprint is generated from the uploaded audio and helps connect a certificate to the track it covers.

<Info>
  Producers must wait for **Verified Unique** before publishing newly uploaded audio. Once a track is available, BeatPass ID presents its licensing and verification details together. A qualifying download or exclusive purchase generates its own license certificate.
</Info>

## What BeatPassID does

When a producer uploads a track, BeatPass analyzes the audio and creates a fingerprint. BeatPass ID combines that fingerprint with the licensing model, Sample-Safe declaration, AI-use disclosure when available, and promised exclusive deliverables. Certificates and public verification tools use the available record to help identify the audio and terms they cover.

## Where fingerprint data appears

- License certificates
- The license certificate modal
- Public verification pages
- Producer upload and track-management tools
- The collapsible **BeatPass ID** section on the track page

## Fingerprint statuses

| Status | What it means |
| --- | --- |
| **Pending** | BeatPass is still analyzing the track audio |
| **Fingerprinted** | BeatPass completed the fingerprint for the saved audio |
| **Failed** | BeatPass could not complete the analysis for this track |

## What fingerprint details can include

When fingerprint analysis is complete, certificates and verification pages can display:

- Fingerprint status
- Fingerprinted date
- Analyzed duration
- Fingerprint hash

## BeatPassID vs similarity search

BeatPassID supports license proof by connecting certificate tools with fingerprint metadata when it is available.

It is different from a similarity search tool. BeatPassID helps document what was licensed; it does not grant permission to copy other tracks or avoid licensing the original work.

  <Accordion title="Certificates are created on download" icon="file-lines" defaultOpen>
    For listeners and buyers, qualifying downloads and purchases create certificates automatically. For producers, a new upload must reach **Verified Unique** before the track can be published.

## Common questions

<AccordionGroup>
  <Accordion title="My certificate seems to be missing — what should I do?" icon="download" defaultOpen>
    Certificates are generated when you download a track. If you cannot find yours, go to **Your library** → **Licenses** and search for the track. If it still does not appear, contact support at contact@beatpass.ca.
  </Accordion>
  <Accordion title="What if fingerprint status shows failed?" icon="triangle-exclamation">
    A failed check blocks a new producer upload from being published. If an older saved track already has a certificate, that certificate remains accessible while BeatPass reviews or reprocesses the fingerprint.
  </Accordion>
  <Accordion title="Does BeatPassID change the audio file I download?" icon="wave-square">
    No. BeatPassID is metadata about the track analysis, not a modification to the downloaded audio file.
  </Accordion>
</AccordionGroup>
