### Documentation Changes

This release includes a complete rewrite of public documentation:

- **API docs** now reflect the current authentication method
- **Payments guide** updated to per-track purchase flow (no cart)
- **Licensing docs** now include the public verification link
- **Embedding docs** corrected with the proper embed format
- **Security docs** updated for authenticator-app two-factor authentication (no SMS)
- **Messaging docs** now include read receipts and typing indicators
- **Collections guide** added
- **Notifications docs** now cover real-time notifications
- **Beat requests** now include rate limit documentation
- **Documentation** expanded to cover: collections, radio, lyrics, coupons, reposts, player, and streaming quota
