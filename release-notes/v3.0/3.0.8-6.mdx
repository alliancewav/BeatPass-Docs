This is an archived release note for the version and date shown. For current instructions, start in [BeatPass Help](/help). Features and instructions below describe that historical release.

## Summary

A complete overhaul of how BeatPass runs background tasks and routine maintenance, designed to handle massive scale without slowing down the app.

## What's New

- **Unified Task Management**: A single, intelligent system now manages all background tasks, replacing multiple overlapping scheduled jobs.
- **Faster Calculations**: Contribution calculations now run far more efficiently, dramatically reducing system load.
- **Time-Budgeted Maintenance**: Routine maintenance tasks now run in controlled time windows, to reduce their effect on the rest of the platform.
- **Smart Prioritization**: Time-sensitive work (like real-time updates and emails) now runs ahead of background analytics, so the things you notice happen first.

## Why It Matters

- **Stability**: The application remains responsive even during heavy background processing.
- **Efficiency**: Server resource usage is reduced by roughly 80%.
- **Scalability**: The new architecture is built to scale with the platform, handling millions of tracks and events efficiently.
